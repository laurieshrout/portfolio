## 1. Summary

Approve with edits is an option where a first-stage approver rejects a template and its associated procedure and elects to make the corrections needed themselves before approving, instead of sending the template or procedure to the submitting author for updates. This scenario is intended only for minor spelling and grammatical changes. The process for how to approve with edits is detailed in this procedure.

## 2. Procedure

1. Select **Start review**.
2. Select the comment icon, input a comment in the text box, and select **Post**.
3. Select **Confirm with edits required**.
4. Complete the review of the template or procedure.
5. Select **Reject** and choose a rejection reason.
6. Select **Submit rejection** > **Edit myself**.
7. Select **Edit template**.
8. Correct the issue.
9. Select the comment icon > **Reply**.
10. Type a reply indicating the changes made.
11. Select **Post & resolve**.
12. Repeat steps 8-11 for additional minor comments.
13. Select **Next** > **Submit for 1st stage review**.
14. Select **Start review**.
15. Select **Confirm as-is**.
16. Select **Approve** once all comments are resolved.
